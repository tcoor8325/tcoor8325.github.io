# Dumb Apps

A museum of silliness: tiny, vibe-coded experiments and single-braincell ideas. Each app is meant to be quick to open, quick to get, and lightly delightful.

## What Lives Here
- Micro-interactions
- One-off jokes in code form
- Small visual or audio gags
- Experiments that would be absurd in a "serious" product

## Apps
- Startup Generator (`apps/startup-generator/index.html`)
- Tone Generator (`apps/tone-generator/index.html`)

## How To Run
- Open an app's `index.html` directly in a browser.
- No build step unless stated in that app's folder.

## Adding A New App (Suggested)
1. Create a folder under `apps/` with a short slug name.
2. Add `index.html`, `style.css`, and `app.js`.
3. Add a tiny `README.md` inside the app folder explaining the joke.

## Tone
Keep it playful, a little weird, and shamelessly low-stakes.
