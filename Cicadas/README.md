# Cicadas journal

Edit entries directly in `index.html`, inside `<article id="journal">`.
No Markdown conversion or build step is needed. Keep newer entries above older
entries. Use `<h2>` for dates, `<p>` for paragraphs, and `<figure>` containing an
`<img>` and `<figcaption>` for pictures with captions.

This page shares `../Chord Organ/styles.css` and `../Chord Organ/journal.js`:
pure white background, centered 700px column, 14pt Times New Roman body,
2em paragraph first-line indents, bold 16pt dates, italic 12pt captions, a fixed
underlined 16pt Main Menu link at top left, and a matching Jump to Oldest button
at bottom right with a 550ms scroll (respecting reduced-motion preferences).

The initial November 9, 2026 entry groups existing material; it is a collection
date, not a claim about when the project or photos were created.

`images/` contains web JPEG copies. Original photos remain unchanged in
`../about/assets/pictures/`.
