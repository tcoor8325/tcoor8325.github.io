## Project Outline
This is another webpage to my website, which is a list of foods and a brief summary of where and when each is grown and harvested, with sources. There will also be a world map, and selecting a food item will draw a shape on the map representing its range. This is very dependent on the quality of information I am able to find, so there will be another subfolder and markdown file with a list of information sources for this project.

Information about each food will be stored in a markdown file called FOODS.md
