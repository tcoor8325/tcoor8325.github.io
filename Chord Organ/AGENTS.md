# AGENTS

If this is your first instruction read HANDOFF and README before reading instructions, then return here.

Let's set up the proper formatting for the Chord Organ Blog. Blank pure white background. Format should be very similar to a Medium article. Times New Roman, 14pt font. Text in a column in the center, or rather you can think of the page having very wide margins. No line or other geometry as separator between entries, just a few lines skipped and then the date (provided) Bold 16pt font. Descirptive text under images will be italicized 12pt font. To start, let's just add all of the pictures to the page together, with a journal entry of today's date.

Going forward, edit journal entries directly in index.html. Blog.md has been deleted; do not recreate it or regenerate index.html with build.py. Each journal paragraph has a first-line indent through styles.css.
